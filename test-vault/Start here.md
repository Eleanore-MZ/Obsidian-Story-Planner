# Story Planner test vault

This vault is for trying out Story Planner during development. It is safe to break: every sample story can be restored from the repository.

The sample stories live in the `Stories` folder. "A Small Story" is a plain two-plot-line story. "The Glass Harbour" uses an invented calendar, two time zones, nested locations, characters, story tags and an off-page event. "Large Story (performance test)" has 320 cards for checking speed.

To rebuild the samples after a format change, run `npm run samples` in the repository folder.
